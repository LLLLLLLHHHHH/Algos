
# SHA-512 实现分析

## 1. 总结
SHA-512 是 SHA-2 系列的 512 位输出算法，采用 64 位字与 1024 位块，与 SHA-256 同族但字长与轮数不同。
- **核心功能**: 将任意长度输入计算为 512 位 (64 字节) 哈希；C 实现提供 `sha512()` 及流式 `sha512_init` / `sha512_hash` / `sha512_done`。
- **标准兼容**: 符合 FIPS 180-4。
- **实现方式**: C 在 `c/SHA512` 中完整实现 80 轮与 K 表；JS 使用 Node `crypto.createHash('sha512')` 或 Web Crypto `SHA-512`。

## 2. 特点与特征

### 64 位与 80 轮
- **消息块**: 128 字节 (1024 位)，扩展为 80 个 64 位字 (`W[80]`)，前 16 字来自输入，后续由 `G0`/`G1` 生成。
- **压缩函数**: 80 轮迭代，使用 `Ch`、`Maj`、`S0`、`S1` 及 80 个 K 常数（前 80 个素数立方根小数部分前 64 位）。
- **IV**: 8 个 64 位初值（前 8 个素数平方根小数部分前 64 位），指纹中常用其低 32 位参与 u32 匹配。

### 上下文设计
- **`sha512_context`**: `buf[128]`、`hash[8]`（64 位）、`bits[2]`（128 位长度计数）、`len` 当前块内字节数。
- **大端序**: 块内字与最终输出均为大端。

## 3. 魔改建议

- **性能**: 80 轮可做部分展开或配合 SHA-NI 类扩展（若平台支持 SHA-512）。
- **HMAC-SHA512**: 在 HMAC 模块中增加 `hmac_sha512`，与现有 HMAC-SHA256 并列使用。
