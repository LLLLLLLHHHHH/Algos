
# Salsa20 C语言实现分析

## 1. 总结
这是一个标准的 Salsa20 流密码算法的 C 语言实现，具体为 Salsa20/20（20 轮）版本。
- **核心功能**: 提供流加密/解密功能。
- **标准兼容**: 符合 eSTREAM 竞赛提交的 Salsa20 规范。
- **参数**: 使用 256 位密钥 (32 字节) 和 64 位 Nonce (8 字节)。

## 2. 特点与特征

### ARX 结构
- 与 ChaCha20 类似，Salsa20 也是基于 **Add-Rotate-Xor (ARX)** 操作构建的。
- 这种设计保证了高性能和抗侧信道攻击能力（Constant-time）。

### 状态矩阵与混合函数
- **状态**: 内部维护一个 4x4 的 32 位整数矩阵（512 位状态）。
    - 这里的布局与 ChaCha20 略有不同（ChaCha20 修改了矩阵的排列以增强扩散性）。
- **Quarter Round (QR)**: 核心混合函数 `QR(a, b, c, d)` 与 ChaCha20 的逻辑不同。Salsa20 的 QR 更新更为“串行”依赖。
- **20 轮迭代**: 每两轮（Double-round）包含一个行混合（Row-round）和一个列混合（Column-round）。

### 64 位计数器与 Nonce
- **计数器**: 使用 64 位计数器（`state[8]` 和 `state[9]`），这使得 Salsa20 可以安全地加密高达 2^70 字节的数据流。
- **Nonce**: 使用 64 位 Nonce（`state[6]` 和 `state[7]`）。

## 3. 魔改建议

### 轮数调整 (Salsa20/8, Salsa20/12)
- **魔改点**: 修改 `salsa20_block` 中的循环次数。
    - 改为 `i < 4` 即为 Salsa20/8。
    - 改为 `i < 6` 即为 Salsa20/12。
- **效果**: 提升速度，Salsa20/12 曾被选为 eSTREAM 软件组的获胜者之一，性能极佳且安全性足够。

### 扩展 Nonce (XSalsa20)
64 位 Nonce 在随机生成时有碰撞风险。
- **魔改点**: 引入 HSalsa20 算法，支持 192 位 Nonce。
- **效果**: 实现 **XSalsa20**，允许使用长随机 Nonce，这正是著名的 NaCl 密码库所采用的方案。

### 演进为 ChaCha20
Salsa20 是 ChaCha20 的前身。
- **魔改点**: 修改 `QR` 函数的内部逻辑，调整矩阵的初始排列。
- **效果**: 变成 ChaCha20，获得更好的扩散性（Diffusion）和在某些架构上更好的性能。

### 密钥流生成器
- **魔改点**: 仅使用 `salsa20_block` 生成随机数流，而不进行异或操作。
- **效果**: 作为一个高质量的密码学安全伪随机数生成器 (CSPRNG)。
