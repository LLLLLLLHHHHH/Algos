# SM4 Algorithm Implementation Analysis

## 1. 总结 (Summary)
该代码是中国国家密码管理局发布的 **SM4 分组密码算法 (GB/T 32907-2016)** 的标准 C 语言实现。
SM4 是一种分组密码算法，分组长度为 128 比特（16 字节），密钥长度也为 128 比特。
该实现提供了基础的密钥扩展功能，以及两种最常用的工作模式：**ECB (电子密码本)** 和 **CBC (密码分组链接)**。
代码结构清晰，依赖极少（仅标准库），易于移植到各种嵌入式或桌面平台。

## 2. 特点与特征 (Features & Characteristics)

### 2.1 算法核心实现
*   **非平衡 Feistel 结构**：核心迭代逻辑清晰地展现了 SM4 的 32 轮非线性迭代结构。
    *   **轮函数 F**：完整实现了 $F(X_0, X_1, X_2, X_3, rk) = X_0 \oplus L(\tau(X_1 \oplus X_2 \oplus X_3 \oplus rk))$ 的逻辑。
    *   **S 盒与线性变换**：使用了预计算的 8-bit S-Box (`SboxTable`) 和线性变换函数 $L$ (`sm4Lt`)。
*   **密钥扩展**：
    *   `sm4_setkey_enc`：正向生成 32 个轮密钥 (`sk`) 用于加密。
    *   `sm4_setkey_dec`：生成轮密钥后，将其逆序排列，从而复用加密函数进行解密（SM4 的解密运算与加密运算结构相同，仅轮密钥使用顺序相反）。
*   **大端序 (Big-Endian)**：
    *   SM4 标准定义使用大端字节序。代码通过内联函数 `GET_ULONG_BE` 和 `PUT_ULONG_BE` 显式处理字节序列与 32 位机器字之间的转换，保证了跨平台的一致性。

### 2.2 工作模式
*   **ECB 模式**：实现了最基础的分组加密，适合独立数据块处理，但无法隐藏明文模式。
*   **CBC 模式**：
    *   支持 IV (初始化向量) 的引入，增强了安全性。
    *   **IV 更新机制**：在处理完一个数据块后，代码会自动更新传入的 `iv` 参数。这种设计允许用户分多次调用函数来处理长数据流（Chaining），而无需手动维护 IV 状态。

### 2.3 代码风格
*   **内联优化**：大量的位操作（移位、异或）和内存读写被封装为 `static inline` 函数，既保证了代码可读性，又利于编译器进行指令级优化。

## 3. 魔改建议 (Modification & Customization)

### 3.1 性能魔改 (Performance Optimization)
*   **查表优化 (T-Table)**：
    *   目前的实现是先查 4 次 S-Box，再进行移位异或计算 $L$ 变换。可以将 S-Box 输出与 $L$ 变换结合，预计算出 4 个 1KB 的大表 (T-Tables)。这样每轮仅需 4 次查表和 4 次异或操作，能显著提升速度（以空间换时间，需注意缓存侧信道攻击风险）。
*   **SIMD 并行化**：
    *   利用 x86 的 AES-NI（虽然是 AES 指令，但部分逻辑通用）或 AVX/NEON 指令集。虽然 CBC 解密和 ECB 可以并行，但 CBC 加密无法并行。
    *   **比特切片 (Bitslicing)**：实现比特切片版本的 SM4，不仅能实现恒定时间执行（防御时序攻击），还能在 32 位/64 位寄存器中同时并行计算 32/64 个数据块。

### 3.2 功能扩展 (Feature Extension)
*   **CTR 模式 (Counter Mode)**：
    *   增加 CTR 模式支持。CTR 模式将分组密码转化为流密码，支持随机访问，且加解密均可并行处理，非常适合现代多核处理器。
*   **GCM 模式 (Galois/Counter Mode)**：
    *   结合 CTR 模式和 GHASH 算法，实现 GCM 认证加密模式。这是现代 TLS 协议和 VPN 中推荐的高性能、高安全模式。
*   **Padding 支持**：
    *   当前的接口要求输入数据长度必须是 16 的倍数。建议增加 PKCS#7 Padding 的自动填充与去除逻辑，使 API 更加用户友好。

### 3.3 硬件适配
*   **协处理器调用**：在支持国密指令集的 CPU（如某些国产鲲鹏、飞腾芯片或 STM32H7 部分型号）上，使用内嵌汇编直接调用 SM4 硬件指令，替代软件轮函数。
