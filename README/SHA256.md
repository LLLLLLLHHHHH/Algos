
# SHA256 C语言实现分析

## 1. 总结
这是一个紧凑且高效的 SHA256 (Secure Hash Algorithm 256-bit) C 语言实现。
- **核心功能**: 提供了流式的哈希计算 API (`init`, `hash`, `done`) 和一步到位的便捷函数 (`sha256`)。
- **标准兼容**: 符合 FIPS 180-4 标准。
- **代码风格**: 代码结构清晰，使用了大量的辅助函数和内联优化。

## 2. 特点与特征

### 64 步迭代与消息扩展
- **消息扩展**: SHA256 将 16 个 32 位字的消息块扩展为 64 个 32 位字 (`W[64]`)。
    - 前 16 个字直接取自输入消息。
    - 后 48 个字通过 `sigma0` 和 `sigma1` 函数（代码中对应 `_G0`, `_G1`）进行复杂的位运算混合生成。
- **压缩函数**: 主循环执行 64 步迭代。
    - 每一轮都涉及 8 个工作变量 (a-h) 的更新。
    - 使用了 64 个常数 (`K[64]`)，这些常数取自前 64 个素数的立方根的小数部分前 32 位。
    - 核心逻辑使用了 `Ch` (Choose), `Maj` (Majority), `Sigma0` (`_S0`), `Sigma1` (`_S1`) 四个非线性函数。

### 上下文设计
- **`sha256_context` 结构体**:
    - `buf[64]`: 64 字节的缓冲区，用于缓存不足一个块的数据。
    - `hash[8]`: 8 个 32 位整数，存储当前的哈希中间值（初始值为前 8 个素数平方根的小数部分）。
    - `bits[2]`: 64 位计数器，记录已处理的数据总位数（分为高 32 位和低 32 位）。
    - `W[64]`: 消息计划数组，包含在 context 中以避免在栈上分配大数组（对嵌入式友好）。

### 大端序处理
- SHA256 算法内部运算基于大端序 (Big-Endian)。
- 代码中通过 `_shb` (shift byte) 和 `_shw` (shift word) 等辅助函数，手动处理了字节序转换，确保在不同架构（大端/小端）的机器上都能产生正确的结果。
- 最终输出时，显式地将 32 位整数拆分为大端序的字节流。

## 3. 魔改建议

### 性能优化：Loop Unrolling
当前的 64 步迭代是在一个 `for` 循环中完成的。
- **魔改点**: 将循环展开，特别是前 16 步（直接读取数据）和后 48 步（需要计算 W）分开处理。
- **效果**: 减少循环开销，利于编译器进行指令调度优化。

### 硬件加速：SHA Extensions
现代 CPU (Intel/AMD x86_64, ARMv8) 提供了专用的 SHA256 指令集。
- **魔改点**: 检测 CPU特性，如果支持，使用内联汇编或 intrinsic 函数调用硬件指令（如 `sha256rnds2`）。
- **效果**: 性能可提升 3-5 倍以上。

### HMAC-SHA256
当前只实现了基础的哈希功能。
- **魔改点**: 封装实现 `HMAC` 结构。
- **效果**: 提供带密钥的消息认证，广泛用于 API 签名（如 AWS S3, JWT）。

### 算法定制：Double SHA256
比特币等加密货币使用 `SHA256(SHA256(data))` 作为工作量证明 (PoW) 算法。
- **魔改点**: 封装一个 `sha256d` 函数，直接对第一次哈希的结果进行二次哈希。
